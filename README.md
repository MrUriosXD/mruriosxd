## 🚀 Proyectos destacados

### 🧩 [ProPortal-MyBB](https://github.com/MrUriosXD/ProPortal-MyBB)

Extensión para **MyBB** basada en ProPortal, adaptada y modernizada para las versiones actuales de MyBB.

Incluye un sistema de portal configurable, bloques, permisos, administración, instalación y diferentes opciones de personalización.

**Tecnologías:** PHP · MyBB · HTML · CSS · MySQL

---

### 🌐 [Enterprise-Development-Studio](https://github.com/MrUriosXD/Enterprise-Development-Studio)

Proyecto orientado al desarrollo de soluciones y herramientas para un entorno de desarrollo empresarial.

**Tecnologías:** HTML · CSS · JavaScript

---

### 🌐 [MyBB Language Translator](https://github.com/MrUriosXD/MyBB-Language-Translator)

Herramienta orientada a facilitar la traducción y gestión de archivos de idioma de **MyBB**.

**Tecnologías:** PHP · HTML · CSS · MyBB

---

### 🌐 [WP Translator Suite](https://github.com/MrUriosXD/WP-Translator-Suite)

Proyecto orientado a la traducción y gestión de recursos relacionados con WordPress.

**Tecnologías:** PHP · HTML · CSS · JavaScript
